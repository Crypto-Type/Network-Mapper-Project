## 📌 Project Overview

This project demonstrates network reconnaissance and enumeration using Nmap against an authorized vulnerable lab machine (Metasploitable).

The objective was to simulate real-world attacker reconnaissance techniques and analyze findings from:

- Ethical Hacker Perspective
- Red Team Analyst Perspective
- VAPT Consultant Perspective
- SOC Analyst Perspective
- Incident Responder Perspective

---

## 🛠 Tools Used

- Kali Linux
- Nmap
- Oracle VirtualBox
- Metasploitable

---

## 🔎 Scans Performed

- Host Discovery
- Full TCP Port Scan
- Service & Version Detection
- OS Detection
- Vulnerability Scanning
- SMB Enumeration
- DNS Enumeration
- Firewall Evasion Testing
- Stealth & Timing Analysis

---

## 🎯 Key Findings

- Multiple exposed legacy services (FTP, Telnet, SMB)
- Outdated service versions vulnerable to known CVEs
- DNS misconfiguration risks
- Large attack surface due to open ports
- Weak firewall filtering

---

## 🏢 Enterprise Security Impact

The project highlights how misconfigured services and unpatched systems significantly increase organizational attack surface.

Proper mitigation strategies include:

- Patch management
- Network segmentation
- IDS/IPS deployment
- Secure configuration baselines
- Continuous monitoring
